# dsh-file-activity 需求清单

> ⚠️ **每次开发本插件的新功能或修复前，必须逐条对照本清单**：新改动不得破坏任何一条既有需求；涉及"会话隔离 / 重启恢复"的需求变更后必须跑回归验证（见 [构建与测试](../开发指南/构建与测试.md#需求回归)）。

## 1. 核心需求

| # | 需求 | 现状 | 验证方式 |
|---|------|------|---------|
| R1 | **重启后恢复**：DSH 进程重启后，历史会话的文件活动数据（最近访问 + 文件统计）必须完整恢复 | 服务端持久化到 `$DSH_HOME/file-activity.json`（防抖 + 原子写），启动时加载；前端刷新/重启后按 sessionId 从服务端重新拉取 | `host-smoke.mjs` 重启恢复断言（8b 节）；手动：重启 DSH → 旧会话仍显示历史数据 |
| R2 | **会话隔离**：新建/切换会话时，各会话只显示自己的文件活动，不残留其他会话数据 | 前端 store 按 `bySession` 分桶（0.4.1），服务端按 sessionId 分桶存储 | `client-render.mjs`；手动：新会话显示空、切回旧会话显示旧数据 |
| R3 | **最近访问 LRU**：每会话最多 5 条；同一文件只出现一次，再次访问移到最前 | server `RECENT_LIMIT=5` + LRU 去重 | `host-smoke.mjs`（7c 节） |
| R4 | **文件统计**：每个文件读取/新增/修改计数 + 首见/最近时间，按绝对路径组织目录树，单子目录链压缩为点号标签，目录可折叠 | server counts + client buildTree/compressChains | `host-smoke.mjs`（计数）、`client-render.mjs`（树/压缩） |
| R5 | **操作分类**：`write` 首次=新增、再次=修改；`edit`/`str_replace_editor`=修改；`read`/`read_image`=读取；absent 观测忽略 | server mapOp + known 表 | `host-smoke.mjs`（1-5 节） |
| R6 | **清空**：可清空当前会话全部记录（服务端持久化同步清） | `POST /file-activity/api/clear` + 前端桶清空 | `host-smoke.mjs`（10 节） |
| R7 | **刷新**：手动刷新拉取最新数据 | `GET /file-activity/api/stats` | 手动 |
| R8 | **自动打开**：每会话首次打开自动显示本页（可在设置关闭） | client installAutoOpen + localStorage 标记 | 手动 |
| R9 | **浮窗预览**：点击文件弹出浮窗，复用 better-sidebar 原生 viewer（代码高亮/Markdown/图片/PDF/HTML）；点击外部/Esc/× 关闭；长文件窗内滚动 | client FloatingPreview + matchFileViewer；**v0.4.4**：媒体字节改走插件自身 `/file-activity/file` 路由（按会话记录授权），工作区外文件（如 `/tmp`）图片/PDF 也能预览 | `client-render.mjs`（预览断言）+ `host-smoke.mjs`（8c/8d 媒体路由断言） |
| R10 | **相对时间**：刚刚/N 分钟前/N 小时前/N 天前/MM/DD；悬停显示完整时间 | client formatRelative | `client-render.mjs` |
| R11 | **UI 设计语言**：DSH 语义 token（`--dsw-alias-*`/`--dsw-font-*`/`--ds-*`），紧凑层级，样式随 activation 注入、teardown 卸载 | client STYLES | 手动视觉 + HMR 检查 |
| R12 | **API 安全**：`/file-activity/api/*` 只接受回环/可信 host，拒绝跨站 | server isTrustedApiRequest | 手动（fence） |

## 2. 用户明确强调过的点（历史踩坑）

- **「重启之后还能恢复我之前的」**（2026-08-23 再次强调）：重启恢复是最容易被其他改动连带破坏的需求，改动任何持久化/前端数据流后必须回归验证 R1 + R2。
- **「会话残留」**（2026-08-23）：之前新会话会显示上一个会话的文件活动，已通过前端 `bySession` 分桶修复（v0.4.1）。
- 状态文件 `file-activity.json` 损坏/缺字段时降级为全新状态，不崩溃（loadState try/catch）。

## 需求变更记录

- **2026-08-24**：R9 浮窗预览补充「工作区外文件可预览」（v0.4.4 媒体路由修复）——侧边栏 `/sidebar/file` 只允许 cwd 内文件，agent 触碰的 `/tmp` 等工作区外路径此前破图；插件自身 `/file-activity/file` 路由按会话记录授权放行，fence 一致。
- **2026-08-23**：新增 R1 重启恢复强调、R2 会话隔离（v0.4.1 修复）；建立本清单，作为后续开发对照基准。
