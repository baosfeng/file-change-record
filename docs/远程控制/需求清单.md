## 验收标准对照（issue #75）

## 资源影响

- **写 IO**：零（无持久化、无磁盘写入；配置经应用层 config 提供）。
- **内存上界**：并发 pending ask/approval 条目数（通常 ≤ 顶层会话数）+ 审计 ≤100 条 + 推送失败记录 ≤50 条。
- **CPU**：事件驱动，仅 ask/approval/end 时工作；出站推送 fire-and-forget 不阻塞事件路径。
- **定时器**：仅可配超时（ask/approval，默认 0 = 不启用）与推送退避一次性 sleep，无周期轮询。
- **网络**：每事件一次出站 POST（重试上限 2 次指数退避 500ms/1s），失败记录不重发（状态接口可补偿）。
- **验证清单**：「资源曲线平稳」项须在真实环境验证时勾选（本插件无后台持续逻辑，预期恒定零开销）。
