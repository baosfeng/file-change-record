# 快速开始

> ⚠️ **何时阅读：** 快速上手前必读。

## 前置条件

- 已安装 `dsh-file-activity` 插件（见 [安装与导入](安装与导入.md)）
- 已安装 `dsh-better-sidebar` v0.12+

## 基础用法

1. 打开侧边栏，`+` 菜单 → **文件活动**（会话首次打开时自动打开本页）。

2. **最近访问**：agent 工具读写文件、侧边栏打开/编辑保存都会记录；LRU 保留 5 条，同一文件只出现一次；点击区块标题可折叠。

3. **文件统计**：读取 / 新增 / 修改次数按绝对路径树形展示（`a/b/c` → `a.b.c`）；点击文件夹展开/收起。

4. **浮窗预览**：点击任意文件弹出浮窗，复用侧边栏内置渲染（代码高亮 / Markdown / 图片 / PDF / HTML）；点击浮窗外或按 `Esc` 关闭。

5. **顶部按钮**：刷新（重载当前数据）、清空（删除当前会话全部记录，需确认）。

## 常见场景

| 场景                        | 操作                            |
| --------------------------- | ------------------------------- |
| 查看 agent 刚才改过哪些文件 | 打开文件活动 → 最近访问列表     |
| 看某个文件被改了几次        | 文件统计 → 找到对应文件查看计数 |
| 快速预览代码/文档           | 点击文件 → 浮窗预览             |
| 清除本次会话记录            | 顶部「清空」                    |
