# 共享工具包（dsh-shared）

> 源码: `plugins/dsh-shared/`（issue #45：多插件间复制粘贴的公共实现抽取合并）

## 概述

`dsh-shared` 是仓库的 **server 端共享工具包**：把多插件间复制粘贴的公共实现抽取为单一来源，依赖方在 `dependencies` 声明 `dsh-shared`（issue #72：dsh-shared 是自家工具库而非宿主提供的运行时，用 dependencies 语义——npm 随插件安装自动安装，用户无需手动装；依赖先发版，见 `scripts/release.mjs` 跨插件依赖校验）。

提供：

| 工具                                                                                     | 说明                                                   | 抽取自                                                                                             |
| ---------------------------------------------------------------------------------------- | ------------------------------------------------------ | -------------------------------------------------------------------------------------------------- |
| `isTrustedApiRequest` / `header`                                                         | Host-header 信任围栏（loopback / trustedHosts / 同源） | 10 个插件的 `lib/fence.js`                                                                         |
| `readJsonBody` / `writeJson` / `writeError`                                              | HTTP JSON 读写工具                                     | 5 个插件的 `lib/http.js` / `routes.js` / `api.js`                                                  |
| `currentProfile` / `profileDirOf` / `patchFileOf` / `extractConfig` / `writePatchConfig` | 配置持久化（cordis.patch.yml YAML 子集读写）           | dsh-my-notify / dsh-task-reliability 的 `lib/config-store.js`、dsh-my-plugin-manager 的 `index.js` |
| `findProjectRoot`                                                                        | 项目根解析（最近 `.git` 祖先）                         | dsh-my-memory / dsh-my-skill-manager                                                               |
| `withTimeout` / `userMessage`                                                            | 超时包装 / user 消息构造                               | dsh-task-reliability / dsh-my-observability                                                        |
| `atomicWriteJson`                                                                        | 原子写 JSON 快照（tmp+rename，自动建目录）             | 4 个插件的 store/persist 原子写逻辑                                                                |

## 使用

```js
import { isTrustedApiRequest, readJsonBody, writeJson } from 'dsh-shared'

// 路由注册时用信任围栏过滤非可信来源
const fence = (request) => isTrustedApiRequest(request, ctx.webRuntime.trustedHosts)

// 处理请求体与响应
const body = await readJsonBody(request)
writeJson(response, 200, { ok: true })
```

依赖方须在 `dependencies` 声明：

```json
{
  "dependencies": {
    "dsh-shared": "^0.1.0"
  }
}
```
