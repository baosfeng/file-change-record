## 回归检查（每次改动后）

- [ ] 功能 1：`npm test`（host 冒烟测试）通过；系统提示中仍能看到 `dsh-think-zh` 指令
- [ ] 功能 2：对话思考块默认展开；文本块 Markdown 正常（渲染由 dsh-md-render 提供，需与 dsh-md-render 同时启用）；图片正常；tool-call 正常
- [ ] 功能 3：轨迹/对话视图界面标签中文；消息正文与代码块未被改动（抽查含 `Model`/`Tools` 等词的代码块仍为原文）
- [ ] 功能 3a：对话/轨迹工具卡片标题为中文（Search→搜索、Bash→命令行、Inspect→检查）；轨迹 Tool Catalog 工具名/描述/参数 JSON 标签为中文；消息正文含 `Search`/`Read` 等英文单词的段落未被改动；`npm test`（含 client-render 第 11 组断言）通过
- [ ] 渲染职责迁移（issue #31）：本插件 bundle 不含 MarkdownView 渲染逻辑（`tryTable`/`MarkdownView` 函数定义已迁出）；`require('dsh-md-render')` 跨插件调用正常；思考模式表格渲染无回归（client-render 表格断言 + dsh-md-render markdown-view 测试）
- [ ] 无副作用：插件禁用/卸载后内置渲染完整恢复（无残留样式、无残留注册、无残留文本替换）
- [ ] 功能 2b（issue #57）：思考内容浅灰 + 斜体 + 略小字号、思考块左侧 accent 强调线，与正式回复（主色正体）一眼可辨；思考内代码块/引用仍可读；`npm test`（含 client-render 第 17 组断言）通过

## 易碎点

- **渲染器替换的恢复性**：`assistant-step` 是 `shadows-shipped-ui` 级替换，卸载/禁用后必须恢复内置渲染，不允许残留。依赖 `ctx.effect` 持有注册 disposer。
- **section 命名冲突**：`systemPrompt.section` 同一层重复 name 会抛错；`dsh-think-zh` 为保留名，不得与第三方插件重复。
- **跨插件依赖（issue #31）**：本插件 client 端 `require('dsh-md-render')`（`dsh.client.external` 声明）——dsh-md-render 未启用时本插件 client 端无法 materialize（硬依赖）；两个插件须同时启用。MarkdownView 渲染样式（`.tzx-md` 系列）随 dsh-md-render 注入，本插件不再注入。
