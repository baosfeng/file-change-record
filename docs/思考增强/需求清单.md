# dsh-think-zh-expand 需求清单

> 维护规则：任何功能开发或修改必须对照本清单做回归检查；新增功能必须在本清单补充条目并添加测试覆盖。

## 需求条目

| # | 需求 | 说明 | 验收标准 | 测试覆盖 |
|---|------|------|---------|---------|
| 1 | 思考与回复强制中文 | Server 端注入固定 system-prompt section（`name: dsh-think-zh`，`order: -90`），指令覆盖思考（reasoning/thinking）与回复 | 组装出的系统提示包含中文指令 section；section 名不与 `chinese-thinking` 冲突 | `test/host-smoke.mjs`（断言 section 注册、name/order/text、PROMPT_TEXT 常量） |
| 2 | 思考内容默认展开 | Client 端替换 `assistant-step` 渲染器：reasoning 块默认展开完整内容，可点击收起，流式中保持展开 | 对话中思考块默认 `aria-expanded="true"` 且完整文本可见；点击标题行可收起；生成中不收起 | `test/client-render.mjs`（思考块展开 + 文本块渲染断言）；手动验证（GUI） |
| 2a | 文本块 Markdown 渲染 | 替换后的文本块渲染器需支持常用 Markdown：代码块 / 标题 / 列表 / 引用 / 表格 / 粗体 / 斜体 / 行内代码 / 链接 | 表格（表头+分隔行+数据行）渲染为 table，对齐规则生效；单元格内行内样式正常；无分隔行的管道行回退段落；行内代码按 CommonMark 语义支持多反引号配对（`` `agent/status` `` 渲染为整体 code，内容含单反引号），单反引号、无内容连续反引号串（````）保持字面量 | `test/client-render.mjs`（表格/对齐/回退/行内样式/多反引号配对断言） |
| 3 | 界面标签中文化 | Client 端 DOM 层精准文本替换：官方 zh 字典缺译与硬编码英文（Thinking / Tool Call / Tools / Duration / Turns / ASSISTANT 等）替换为中文；只替换完全匹配的叶子文本节点，排除代码块/输入区 | 轨迹视图与对话视图的已知英文标签显示为中文；消息正文、代码块内容不被改动；React 重渲染后仍生效 | 手动验证（独立实例 + 无头浏览器）；client 语法由 CI `node --check` 覆盖 |
| 3a | 工具卡片标题 / 工具名 / 描述中文化 | 官方工具卡片标题（VARIANT_TITLES：Search/Bash/Read/Write/Edit/Code 等）与工具自有标题（Inspect / Run Cordis Plugin 等）在工具调用卡片行内（祖先含 `data-chat-call-id`）替换为中文；轨迹视图 Tool Catalog 的工具名与描述按「工具名→中文」映射整体替换（描述按工具名索引，不匹配英文原文）；others 卡片摘要 `工具名 · …` 的前缀工具名替换 | 对话/轨迹卡片标题显示中文（Search→搜索、Bash→命令行 等）；Tool Catalog 条目名称/描述/`parameters JSON` 标签为中文；消息正文中与工具名同形的单词不被改动；未覆盖工具保留英文；映射纯函数（zhCardTitle/zhToolName/zhToolDesc/zhCardSummary）可被测试断言 | `test/client-render.mjs` 第 11 组（映射纯函数断言）；手动验证（对话卡片 + 轨迹 Tool Catalog） |

## 回归检查（每次改动后）

- [ ] 功能 1：`npm test`（host 冒烟测试）通过；系统提示中仍能看到 `dsh-think-zh` 指令
- [ ] 功能 2：对话思考块默认展开；文本块 Markdown 正常；图片正常；tool-call 正常
- [ ] 功能 3：轨迹/对话视图界面标签中文；消息正文与代码块未被改动（抽查含 `Model`/`Tools` 等词的代码块仍为原文）
- [ ] 功能 3a：对话/轨迹工具卡片标题为中文（Search→搜索、Bash→命令行、Inspect→检查）；轨迹 Tool Catalog 工具名/描述/参数 JSON 标签为中文；消息正文含 `Search`/`Read` 等英文单词的段落未被改动；`npm test`（含 client-render 第 11 组断言）通过
- [ ] 无副作用：插件禁用/卸载后内置渲染完整恢复（无残留样式、无残留注册、无残留文本替换）

## 易碎点

- **渲染器替换的恢复性**：`assistant-step` 是 `shadows-shipped-ui` 级替换，卸载/禁用后必须恢复内置渲染，不允许残留。依赖 `ctx.effect` 持有注册 disposer。
- **section 命名冲突**：`systemPrompt.section` 同一层重复 name 会抛错；`dsh-think-zh` 为保留名，不得与第三方插件重复。
