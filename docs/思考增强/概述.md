# 思考增强（dsh-think-zh-expand）

> 模块文档：`docs/思考增强/` — 源码：`plugins/dsh-think-zh-expand/`

**dsh-think-zh-expand** 是 DSH 思考增强插件，实现两个功能：

1. **思考与回复强制中文**（Server 端 `plugins/dsh-think-zh-expand/lib/index.js`）：通过 `ctx.systemPrompt.section()` 注入固定中文指令（`name: dsh-think-zh`、`order: -90`），让 agent 无论用户使用什么语言，思考（reasoning/thinking）与回复都使用中文。
2. **思考内容默认展开**（Client 端 `plugins/dsh-think-zh-expand/lib/client.js`）：替换 `conversation.chat.node` 的 `assistant-step` 渲染器，reasoning 块**默认展开完整内容**（点击标题行可收起、流式生成中强制保持展开）；文本块配轻量 Markdown 渲染，图片复用内置 `renderMessageImages`。
3. **界面标签中文化**（Client 端 `plugins/dsh-think-zh-expand/lib/client.js`）：官方 UI 的 zh 字典缺译与硬编码英文（Thinking / Tool Call / Tools / Duration / Turns / ASSISTANT 等）经 DOM 词表替换为中文；**工具卡片标题**（Search / Bash / Read / Write / Edit / Code / Inspect 等，官方标注 "design literals, not translatable copy"）在工具调用卡片行内替换为中文；**轨迹视图 Tool Catalog** 的工具名与描述（web_search + 英文描述）按工具映射表整体中文化；others 卡片摘要 `工具名 · …` 的前缀工具名同步替换。

## 业务场景映射

| 业务关键词 | 入口 | 说明 |
|---|---|---|
| 思考中文 / 中文提示 / reasoning 中文 | `plugins/dsh-think-zh-expand/lib/index.js` `apply()` | 注册 system-prompt section，注入中文思考与回复指令 |
| 思考展开 / Think 展开 / 思考折叠 | `plugins/dsh-think-zh-expand/lib/client.js` `AssistantStepView` / `ThinkBlock` | 替换 assistant-step 渲染器，思考块默认展开、可交互折叠 |
| 界面标签 / 工具中文化 | `plugins/dsh-think-zh-expand/lib/client.js` `ZH_TABLE` / `CARD_TITLE_ZH` / `TOOL_NAME_ZH` / `TOOL_DESC_ZH` | 固定英文标签、工具卡片标题、Tool Catalog 工具名与描述替换为中文 |
| Markdown 渲染 / 代码块 | `plugins/dsh-think-zh-expand/lib/client.js` `MarkdownView` / `mdInline` | 文本块轻量 Markdown（代码块/标题/列表/引用/粗体/行内代码/链接） |
