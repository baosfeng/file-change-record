# dsh-md-render 需求清单

## 回归检查（每次改动后）

- [ ] `npm test`（表格检测单测 + client 渲染路径 + MarkdownView 单测 + 复制按钮单测 + 表格交互单测/渲染断言 + tokenizer 单测 + 代码块增强渲染断言 + 配置 API 单测 + 渲染开关断言 + Gherkin 验收）通过
- [ ] 构建产物 `lib/client.js` 语法检查通过（`node --check`）
- [ ] 与 dsh-think-zh-expand 共存时表格正常渲染（手动/真实环境）；think-zh-expand `npm test` 全绿（双 bundle 加载）
- [ ] 思考模式（reasoning 块）表格渲染不受影响（回归）
- [ ] mermaid 代码块容器（`div.md-code-block`）结构保持，dsh-mermaid-render `npm test` 全绿（无改动）
- [ ] 复制按钮：代码块/内容按钮渲染、点击复制内容正确（不含语言标记/按钮文案）、clipboard 失败回退 execCommand、流式中隐藏（`test/copy-button.mjs`）；代码块复制按钮与语言标签同排共存（issue #80）
- [ ] 代码块增强（issue #80）：语法高亮 token span、语言标签、行号（开关）、未知语言回退纯文本、超长跳过高亮（`test/tokenizer.mjs` / `test/codeblock-render.mjs`）
- [ ] 语法补全（issue #81）：任务列表（checkbox 勾选态、位于文本之前）、删除线（`<del>`）、图片（`<img>` src/alt 正确、alt 兜底）、多级嵌套列表（`ul`/`ol` 层级正确）；与现有语法共存不冲突（`test/syntax-complete.mjs`）；与 dsh-think-zh-expand / dsh-mermaid-render 共存回归
- [ ] 无副作用：插件禁用/卸载后无残留样式、无残留表格

## 易碎点

- **构建产物**：`lib/client.js` 是构建产物（parts 拼接），修改 `client.src.js` 或 `lib/parts/` 后必须 `npm run build` 并提交产物；CI 不执行构建。
- **检测规则**：表格检测规则（`isTableLine` / `isSeparatorLine` / `parseTable`）是核心逻辑，改动必须同步更新 `test/table-detect.mjs` 并保持全绿。
- **输出结构兼容（issue #31）**：MarkdownView 输出类名（`div.tzx-md` / `p.tzx-p` / `table.tzx-table` / `div.md-code-block`）是跨插件契约——dsh-md-render 的 scanner 扫描 `p.tzx-p`、dsh-mermaid-render 扫描 `div.md-code-block`、think-zh-expand 的测试断言这些结构；改动类名必须同步更新三个插件的测试。
- **复制按钮结构（issue #74）**：`div.md-code-block` / `div.tzx-md` 内新增 `button.dsh-md-render-copy` 子元素——mermaid-render 扫描 `div.md-code-block` 用 `querySelector('code')` 不受影响；think-zh-expand 测试展开函数组件会收集按钮文本「复制」，其断言不受影响；改动按钮类名/文案需同步更新三个插件测试。issue #80 将代码块复制按钮移至头部（`div.dsh-md-render-code-head` 内，与语言标签同排），`.md-code-block>.dsh-md-render-copy` 定位选择器改为头部内布局，功能（clipboard + execCommand 回退 + 流式隐藏）不变。
- **代码块增强结构（issue #80）**：`div.md-code-block` 内新增头部 `div.dsh-md-render-code-head`（语言名 + 复制按钮）与 `code` 内 `div.dsh-md-render-code-line` 行号 div（CSS counter 伪元素，不进入文本内容）——tokenizer（`test/tokenizer.mjs`）与渲染（`test/codeblock-render.mjs`）是核心逻辑；mermaid 扫描 `pre.textContent` / 复制按钮读 `code.textContent`，行号用伪元素不污染，改动不得引入行号到文本节点；新增/改动 parts 需在 `client.src.js` 与 `scripts/build.mjs` 同步占位符。
- **跨插件导出**：`exports.MarkdownView` 是 think-zh-expand 的跨 bundle require 契约（`dsh.client.external`），删除/改名会破坏 think-zh-expand 的 client 端 materialize。
- **表格交互（issue #83）**：排序/折叠状态存 scroll 容器 dataset（`sortCol` / `sortDir` / `totalRows`），事件委托绑定在 scroll 容器 click 上——改动渲染结构（th/折叠按钮/折叠行 class）必须同步更新 `test/table-interact-render.mjs` 与 Gherkin 场景；折叠行用 class + CSS 隐藏（`tr[hidden]` 会被作者样式覆盖，不可用）。
- **配置化（issue #84）**：增强开关状态（`renderOptions`）定义在 `config.part.js`（`setRenderOptions` / `pickRenderOptions`），其余 parts 渲染时读取——开关名（11 个）在 server 端（`lib/index.js` `SWITCH_KEYS` / `lib/routes.js` `SWITCH_KEYS`）与 client 端（`config.part.js` `DEFAULT_RENDER_OPTIONS` / `settings.part.js` `SETTINGS_SWITCHES`）三处必须同名一致；新增开关需三处同步 + `test/config-switches.mjs` 断言；patch 写入行 id 为 `md-render`（与 `cordis.patch.yml` 一致，改名会破坏持久化恢复）；server 端新模块（`lib/routes.js`）纳入覆盖率门禁（`vitest.config.mjs` include + 阈值）。
