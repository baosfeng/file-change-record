# 通知提醒（dsh-notify）

> 模块文档：`docs/通知提醒/` — 源码：`plugins/dsh-notify/`

**dsh-notify** 是 DSH 通知提醒插件：在**会话（本轮对话）结束**、**agent 询问问题**、**等待用户批准**时，向浏览器推送**系统通知 + 提示音**，点击通知直接跳转到对应会话；并提供**远程 hook 触发接口**（`POST /notify/api/trigger`）供任意进程 / cron / CI / webhook 推送自定义通知。

## 业务场景映射

| 业务关键词 | 入口 | 说明 |
|---|---|---|
| 会话结束提醒 / turn 结束 / agent idle | `plugins/dsh-notify/lib/index.js` `agent/status` 监听 | `running → idle` 视为本轮对话结束，推送 `kind: end` 通知（默认过滤子代理会话；`subagentEnd: true` 后子代理完成也推送，标题带「子代理」前缀） |
| 询问提醒 / ask 提醒 / 等待回答 | `plugins/dsh-notify/lib/index.js` `tools/pre-execute` 监听 | 命中 `ask_user_question` 工具时推送 `kind: ask` 通知，`next()` 透传不干扰工具执行 |
| 审批提醒 / 等待批准 | `plugins/dsh-notify/lib/index.js` `approval/request` 监听 | 推送 `kind: approval` 通知，`next()` 透传不干扰审批流程 |
| 浏览器通知 / 滴声 / toast | `plugins/dsh-notify/lib/client.js` | EventSource 订阅 SSE 帧 → 系统通知（Notification）+ Web Audio 滴声 + 页面 toast 兜底，点击跳转会话 |
| 远程 hook / webhook 触发 | `plugins/dsh-notify/lib/index.js` `POST /notify/api/trigger` | 本机 loopback 围栏，可选 `apiToken` 供远程主机调用 |
| 实时通道 / SSE | `plugins/dsh-notify/lib/index.js` `GET /notify/api/stream` | SSE 长连接，25s 心跳，断线自动重连，多标签页共享 |
