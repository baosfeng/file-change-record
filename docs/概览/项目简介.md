# 项目简介

**个人 DSH（DeepSeek Harness）插件集合仓库**：轻量多插件目录，每个插件位于 `plugins/<name>/`，自包含、可独立安装与发布。

## 基本信息

| 项 | 值 |
|----|----|
| 项目名 | my-dsh-plugins |
| 版本 | 各插件独立 semver（当前主插件 dsh-file-activity v0.4.0） |
| 语言 | JavaScript（Node.js ≥ 20，ESM） |
| 类型 | 基础服务（DSH 插件集合） |
| 技术栈 | Node.js + Cordis 4（插件框架）+ React 18（client 渲染）+ dsh-better-sidebar（侧边栏扩展服务） |
| 仓库 | https://github.com/baosfeng/my-dsh-plugins |

## 插件列表

| 插件 | 版本 | 简介 |
|------|------|------|
| [dsh-file-activity](https://github.com/baosfeng/my-dsh-plugins/tree/main/plugins/dsh-file-activity) | 0.4.0 | 侧边栏文件活动页签：记录文件读取/新增/修改历史与统计，按文件夹平铺展示，点击即用原生预览打开 |

## 仓库结构

```
├── plugins/                    # 所有插件（每目录一个自包含插件）
│   └── dsh-file-activity/
│       ├── lib/index.js        # server 端入口（事件监听/HTTP 路由/持久化）
│       ├── lib/client.js       # client 端入口（浏览器页签注册）
│       ├── test/               # 冒烟测试（CI 执行）
│       ├── package.json        # 独立包（exports 分 server/client）
│       ├── cordis.patch.yml    # bundle 挂载补丁
│       └── README.md / CHANGELOG.md / LICENSE
├── skills/                     # 本仓库开发技能（SKILL.md 格式，可安装到 ~/.dsh/skills/）
│   └── dsh-plugin-development/
├── docs/                       # 通用文档与设计文档（本文档体系）
├── .github/workflows/          # CI（遍历插件测试）与 Release（tag 触发）
└── AGENTS.md                   # AI 代理入口（定位→读取→理解→编码）
```

## 发布约定

- 只发布 **GitHub Release**（不发布 npm）。
- tag 格式：`<包名>@v<版本>`（如 `dsh-file-activity@v0.1.0`），由 `.github/workflows/release.yml` 自动打包并创建 Release。
- 每个插件独立版本号（semver）、独立 CHANGELOG（Keep a Changelog 格式）。
- 许可：每个插件各自携带 MIT LICENSE；仓库级文档默认 MIT。
