## 2. 用户明确强调过的点

- **纯官方依赖**（issue #22 精神）：client 面板挂在官方 `slots` 扩展点（`settings.plugins.tab`），不依赖 dsh-better-sidebar；server 端只用官方 `ctx.systemPrompt` / `ctx.tools` / `webServer` / `webRuntime` 服务；工具定义直接构造（不导入 `@deepseek-ai/dsh-tools`——本仓库插件只解析 Node 内置模块与相对路径）。
- **记忆绝不静默变更**：所有写操作（新增/修改/删除）必须经用户确认（`confirmed: true`），服务端强制校验。
- **注入有上限**：全局记忆注入系统提示词受条数（`maxItems`）与单条长度（`maxDescLength`）双重上限，避免提示词膨胀。
