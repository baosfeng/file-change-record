# 记忆（dsh-my-memory）

> ⚠️ **何时阅读：** 想让 agent 记住你的长期偏好（回复语言、代码风格）或项目约定（技术栈、目录规范）时，或修改本插件代码前。

## 功能一句话

**全局/项目两级记忆持久化：全局记忆在会话开始时注入系统提示词（agent 始终携带），设置页可视化面板管理（新增/修改/删除均需自定义确认 UI 确认），`memory_query` 工具只读查询记忆详情。**

## 解决的问题

DSH 的 agent 每次会话都从零开始：用户反复交代的偏好（「回复用中文」「代码注释写中文」）和项目约定（「本项目用 vitest」「不要动 docs/」）无法持久化，每次新会话都要重新说明。本插件补上这个空白（issue #38）：

1. **两级记忆**：全局记忆（跨项目，如用户偏好、常用习惯）+ 项目记忆（按项目 cwd 隔离，如项目约定、技术栈决策）；
2. **系统提示词注入**：会话开始时把全局记忆注入系统提示词，agent 始终携带用户关键偏好；
3. **可视化面板**：设置页查看/修改/删除记忆，写操作必须用户确认（自定义确认 UI：删除红色、保存绿色）；
4. **工具查询**：`memory_query` 只读工具让 agent 查询记忆详情。

## 工作机制

```
设置 → 插件 → 记忆（官方 slots 扩展点，纯官方依赖）
        ↓ GET /my-memory/api/memory?scope=global|project&cwd=…
        ↓ POST /my-memory/api/memory（add/update/delete，必须携带 confirmed: true）
<项目根>/.dsh/memory.json（项目记忆，按 cwd 向上找 .git 定位项目根）
$DSH_HOME/memory.json（全局记忆）
        ↓ 原子写（tmp+rename）+ 防抖（300ms 合并写盘）+ 启动 load() 恢复
        ↓ 系统提示词注入
ctx.systemPrompt.section({ name: 'dsh-my-memory', order: -95,
  text: (context) => 读取全局记忆缓存，注入最新 maxItems 条（默认 5），
        每条截断 maxDescLength 字符（默认 200）})
  → 每次组装系统提示词时求值：会话开始即注入，记忆变更后下一轮即时生效
        ↓ 工具
ctx.tools.register(memory_query)（只读：全局/项目过滤 + 关键词过滤，
  项目 cwd 取会话工作目录 exec.agent.session.header.cwd）
```

## 业务场景映射

| 业务关键词                                  | 入口与方法（源码路径）                                                                                                                                                     |
| ------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 两级记忆存储（原子写 + 防抖 + 重启恢复）    | `plugins/dsh-my-memory/lib/store.js`（server）— `createStore()` / `globalMemoryFile()` / `projectMemoryFileOf()` / `findProjectRoot()`（`.git` 向上查找）                  |
| 系统提示词注入                              | `plugins/dsh-my-memory/lib/prompt.js` — `createMemorySection()`（section `dsh-my-memory`，order -95，text provider 每次组装求值，`maxItems`/`maxDescLength` 上限）         |
| memory_query 只读工具                       | `plugins/dsh-my-memory/lib/tool.js` — `createMemoryQueryTool()`（JSON Schema 参数/输出直接构造，不导入第三方包）                                                           |
| 写操作 API（需用户同意标记）                | `plugins/dsh-my-memory/lib/api-route.js` — `GET /my-memory/api/memory`（查询）、`POST /my-memory/api/memory`（add/update/delete，`confirmed: true` 强制）                  |
| 信任围栏                                    | `plugins/dsh-my-memory/lib/fence.js` — 回环/可信 host 校验                                                                                                                 |
| 设置页面板（全局/项目分区 + 自定义确认 UI） | `plugins/dsh-my-memory/lib/client.js`（client）— `ctx.slots.inject('settings.plugins.tab', …)`；删除红色二次确认、保存/新增绿色确认、项目 section 蓝色 accent + 项目根徽标 |

## 安装与使用

1. 安装插件：

   ```bash
   dsh plugin --profile web add dsh-my-memory
   ```

2. 打开 DSH Web 设置 → 插件 → **记忆**；
3. **全局记忆**区块：输入要记住的内容 → 绿色「新增」→ 绿色确认面板「确认保存」→ 写入 `$DSH_HOME/memory.json`；条目可「编辑」（绿色保存确认）或「删除」（红色确认面板 + 红色「确认删除」二次确认）；
4. **项目记忆**区块：顶部输入项目根路径 → 「加载」→ 该项目记忆显示（蓝色 accent + 项目根徽标），操作同全局；
5. 新会话开始时，全局记忆自动注入系统提示词（agent 可见）；agent 也可用 `memory_query` 工具查询记忆详情（含项目记忆）。

## 配置

插件配置（`cordis.yml` 中 `my-memory` 的 `config` 字段）：

```jsonc
{
  "maxItems": 5, // 注入系统提示词的全局记忆条数上限（默认 5）
  "maxDescLength": 200, // 单条记忆注入长度上限（字符，默认 200）
}
```

## 边界与限制

- 项目记忆以 `cwd` 向上找 `.git` 定位项目根；无 `.git` 时退回 `cwd` 自身；
- 项目记忆文件 `<项目根>/.dsh/memory.json` 随仓库提交（与 dsh-my-skill-manager 同模式）；若不想版本化可在 `.gitignore` 中排除；
- 系统提示词只注入**全局**记忆（项目记忆按项目隔离，agent 需用 `memory_query` 查询）；
- 注入受条数/长度上限约束，超出部分不注入（避免提示词膨胀）；
- 面板为可选增强：`ctx.get('slots')` 缺省时静默跳过注册，server 端记忆能力不受影响（与「纯官方依赖」原则一致，不依赖 dsh-better-sidebar）。
